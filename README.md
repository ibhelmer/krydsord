# Krydsord – ordlister

Dansk ordliste over cybersikkerhedsbegreber til brug i undervisning og til generering af krydsord.

## Ordliste

`ordlister/cybersikkerhed_ordliste.csv` indeholder 220 cybersikkerhedsbegreber med forklaringer og ledetråde, inddelt i faglige kategorier.

CSV-filen anvender semikolon som separator og har kolonnerne `id`, `term`, `crossword_answer`, `definition`, `clue`, `category`, `difficulty` og `language`.

- `crossword_answer`: svar uden mellemrum eller specialtegn
- `difficulty`: sværhedsgrad fra 1 til 5
- `language`: sprogkode for forklaringen (`da`)
